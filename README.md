# きーくんの依頼一覧：GitHub入口

本人限定の依頼一覧を開くための、静的な入口ページです。

## 使い方

GitHub Pagesの入口で「依頼一覧を開く」を押すと、既存の本人限定サイトへ移動します。必要に応じてChatGPTでログインしてください。

## 公開範囲

- このリポジトリと入口ページは公開です
- 依頼の本文、作業報告、成果物データ、認証情報は、このリポジトリに含めていません
- 一覧本体、ログイン、保存データは、既存の本人限定サイトで管理しています
- この入口は一覧アプリの移転、代理認証、データのコピーではありません
- 外部スクリプト、解析、フォーム、Cookieやブラウザ保存は使用しません

## 配信

GitHub Pagesで main ブランチのルートを配信します。公開対象は index.html の静的な入口です。機密情報や一覧本体のソースをこのリポジトリへ追加しないでください。
